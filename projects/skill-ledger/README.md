# 📊 Skill Ledger - Online Learning Platform

**Database Design & Business Intelligence Project**

---

## 📋 Project Overview

A comprehensive data analysis project for an online learning platform featuring student enrollment tracking, course management, and performance analytics. This project demonstrates expertise in database design, SQL development, and business intelligence.

**Project Type:** Database Design + Business Intelligence  
**Technologies:** MySQL, SQL, Power BI, Excel  
**Status:** ✓ Completed  
**Complexity:** Advanced  

---

## 🎯 Project Objectives

✅ Design a normalized relational database for learning platform  
✅ Implement data integrity and business rules through constraints  
✅ Develop business intelligence queries for strategic insights  
✅ Create interactive dashboard for KPI monitoring  
✅ Generate actionable recommendations from data analysis  

---

## 📊 Database Architecture

### Tables Designed
1. **Students** - Student demographic and learning preference data
2. **Courses** - Course catalog with pricing and categorization
3. **Enrollments** - Student enrollment records with performance metrics

### Key Features
- Normalized design (3NF)
- Foreign key relationships
- Data validation constraints
- Business rule enforcement

**Database Size:** 1000+ student records across multiple tables

## 🔍 SQL Queries & Analysis

### Query 1: Student Acquisition Metrics
**Question:** How many students have signed up on the platform?
- Measures user base growth
- Tracks platform adoption
- Supports capacity planning

### Query 2: Course Distribution
**Question:** How many courses are available under each category?
- Identifies category-wise portfolio
- Highlights expansion opportunities
- Supports strategic planning

### Query 3: Revenue Analysis
**Question:** What is the average course fee for each category?
- Analyzes pricing strategy
- Identifies premium categories
- Supports revenue optimization

### Query 4: Learning Mode Preferences
**Question:** How many students prefer each learning mode?
- Determines content delivery priorities
- Supports resource allocation
- Improves student experience

### Query 5: Certification Success
**Question:** How many certificates have been issued?
- Measures completion rates
- Reflects learning effectiveness
- Indicates engagement levels

### Query 6: Demographic Analysis
**Question:** Which education level has enrolled in highest courses?
- Identifies primary audience segments
- Reveals market preferences
- Supports marketing strategy
