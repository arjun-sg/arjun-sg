## Project 1: Skill Ledger - Online Learning Platform

**Type:** SQL Database Design + Power BI Analytics  
**Status:** Completed  

### 📋 Overview

An end-to-end data analytics project for an online learning platform. Demonstrates database design, SQL analysis, and business intelligence through interactive dashboards.

---

## Database Design

### Schema
3 main tables with relational structure:

**Students** - Student demographics and preferences  
**Courses** - Course catalog with pricing and categories  
**Enrollments** - Enrollment records and performance metrics

### Key Features
- Normalized design (3NF)
- Foreign key relationships
- Data validation constraints
- Referential integrity

---

## SQL Analysis

### 6 Business Queries

| # | Query | Purpose |
|---|-------|---------|
| 1 | Student Acquisition | Total platform users |
| 2 | Course Distribution | Portfolio by category |
| 3 | Revenue Analysis | Pricing by category |
| 4 | Learning Preferences | Content delivery insights |
| 5 | Certification Metrics | Completion rates |
| 6 | Demographic Analysis | Student segmentation |

Each query includes business insights and recommendations.

**File:** [010_Business_Queries.sql](../projects/skill-ledger/sql/010_Business_Queries.sql)
